# 良渚文献目录站 · 数据契约（v1.0）

> 契约冻结日期：2026-10-27
> 用途：后端（导入 / API / 图谱）与前端（单页应用）**必须**按本文档实现；改动需同步改本文档。
> 决策依据：课件第 11 / 13 页 → 第一版做「浏览 / 检索 / 详情 / 来源」+ 一个最小图谱页。

---

## 0. 总体

- **后端**：Python 3.13 + FastAPI + SQLite（单文件 `data/lzkg.db`）
- **前端**：单文件 `web/static/index.html`（原生 JS，不引 CDN，**必须断网可用**）
- **访问**：仅本机 `127.0.0.1`，端口默认 **8771**（可配置）
- **数据库**：全量迁移 —— 200 篇文献 + 3 162 条图像元数据 + 标签 + **4.0.12 原始 JSON 全文**（可检索）

### 1.3 标签（规范化，最小图谱页的节点来源）

- `tags(tag_id PK, dim, code, name, lit_count, img_count, raw_forms, code_reliable)`
  - `dim` ∈ `period` | `region` | `topic` | `lineage` | `img_type` | `obj_type`
  - `tag_id` = `dim:名称`（**以名称为身份**，不是 `dim:code`）
  - `raw_forms`：该标签在登记表里的原始写法（可能多种，用 `；` 连接）
  - `code_reliable`：0/1，该码位是否可作聚合依据
- `lit_tags(lit_id, tag_id, dim, PK(lit_id,tag_id))`
- `img_tags(img_id, tag_id, dim, PK(img_id,tag_id))`

**规范化规则（必须实现）**：
1. 四维标签按 `；` 或 `;` 拆多值 → 逐条 trim
2. 每条再拆「代码 名称」：匹配 `^([A-Z]-\d{4})\s+(.+)$` → code/name；匹配不到则 code 为空、name 为整条
3. 括号限定后缀（如 `良渚文化（数字展示）`）**拆成两个字段**：name=`良渚文化`，不产生新实体
4. **一码多义的码位自动标记 `code_reliable=0`**（★ 实测驱动，不是硬编码）
   实测库里 **5 个码位下藏着 54 个不同名称**：`S-0802`×18、`S-0801`×11、`S-0803`×9、
   `R-0199`×8、`S-0804`×8。
   → **这些「代码」是族系代号，不是标签代号。**
   → 处置：**照旧按「名称」建独立标签（信息不丢）**，同时把该码位标为 `code_reliable=0`。
   → ⚠️ **绝不能按代码合并**——那会把「环太湖」和「文化创意」并成同一个东西，
     把「GIS」和「数字化保护」并成同一个东西。
   （为什么不塞进「未细分」桶？那样会把「环太湖」的 31 条信息一并丢掉。）
5. 同一 `dim+name` 只保留一条 `tags` 记录，`raw_forms` 累加不同写法
6. 检测方式：迁移时先按 `(dim, code)` 统计 `COUNT(DISTINCT name)`，>1 的码位全部标为不可靠。
   **不硬编码码位名单**——码位表会随教师发布的新版词表变化。

### 1.4 原始 JSON 全文（4.0.12 原件，用户明确要求可检索）

- `raw_json(rowid PK, lit_id, filename, size_bytes, text, UNIQUE(lit_id,filename))`
- `raw_json_fts` —— FTS5 trigram **外部内容**虚拟表：`content='raw_json', content_rowid='rowid'`
  （索引只存倒排、不复制正文：113MB 的 JSON 全文因此不被复制一份，库省约 113MB）
- 灌库后用 `INSERT INTO raw_json_fts(raw_json_fts) VALUES('rebuild')` 重建索引

### 1.5 全文检索

- `docs_fts` —— FTS5 trigram 虚拟表：`(title, content, lit_id UNINDEXED)`
  - `content` = `03_文献全文/` 下对应 MD 的全文

### 1.6 图谱（L1 表派生，零抽取）

- `graph_nodes(node_id PK, kind, label, lit_id, weight)`
  - `kind` ∈ `lit` | `img` | `tag` | `objtype`
- `graph_edges(src, dst, rel, lit_id, weight, PK(src,dst,rel,lit_id))`
  - `rel` ∈ `contains`（lit→img）| `depicts`（img→objtype）| `tagged`（lit→tag）| `imgtag`（img→tag）| `cocite`（lit→lit，共享同一 tag）

### 1.7 `meta`

`key/value`，至少记录：`migrated_at`、`source_root`、`lit_count`、`img_count`、`tag_count`、`raw_json_count`、`docs_fts_count`、`review_pass_count`、`schema_version`

所有响应为 JSON；错误统一 `{"error": "..."}`，HTTP 400。

### 2.1 `GET /api/overview`
```json
{
  "lit_count": 200, "img_count": 3162, "tag_count": 137, "raw_json_count": 200,
  "md_total_chars": 1649167, "docs_fts_count": 200,
  "by_doc_type": [{"k":"DOC-AR｜学术论文","n":163}],
  "by_lang": [{"k":"zh｜中文","n":125}],
  "by_year": [{"k":"2018","n":12}],
  "by_source_type": [{"k":"S1｜中国知网(CNKI)","n":108}],
  "by_open_type": [{"k":"公开（知网/维普下载）","n":69}],
  "by_period": [{"k":"新石器时代晚期","n":106}],
  "review": {"pass": 619, "pending": 2516, "other": 27, "rate": 0.196},
  "updated_at": "2026-10-27 20:13:09",   // 与 migrated_at 同值（别名）
  "note": "复核状态按 images.review_status 统计；有日期不等于已复核"
}
```

### 2.2 `GET /api/literatures`
查询参数（**全部取交集 / AND 语义**）：
`page`(1起) `size`(默认20，最大100) `q`(关键词) `doc_type` `lang` `year` `period` `region` `topic` `lineage` `open_type` `source_type` `sort`(`lit_id`|`year`|`title`)

响应：
```json
{"total": 200, "page": 1, "size": 20, "items": [ { ...literatures 行... } ]}
```
- `q` 命中时：**关键词在 MD 全文命中**（FTS5 trigram，2 字词降级 LIKE）；同时在题名/作者/关键词里命中也算
- 多值标签参数用 `,` 分隔，**任一命中即算该维度命中**（维度内 OR，维度间 AND）

### 2.3 `GET /api/literatures/{lit_id}`
```json
{
  "lit": { ...literatures 行... },
  "images": [ { ...images 行... } ],
  "raw_json": [{"filename":"...","size_bytes":123,"snippet":"..."}],
  "tags": {"period":[...],"region":[...],"topic":[...],"lineage":[...]},
  "md": {"path":"...","chars":16480,"pages":9,"img_refs":2,"excerpt":"正文前 1200 字"},
  "similar": [ {"lit_id":"LIT-000xxx","title":"...","shared_tags":["..."]} ]
}
```

### 2.4 `GET /api/images`
`lit_id` `page` `size` `img_type` `obj_type` `review_status` `q`（图注文本）
响应同 §2.2 结构，字段为 images 行。

### 2.5 `GET /api/tags?dim=&limit=`
```json
{"items":[{"tag_id":"region:R-0101","dim":"region","code":"R-0101","name":"良渚古城","lit_count":75,"img_count":12,"raw_forms":["R-0101 良渚古城"]}]}
```

### 2.6 `GET /api/graph`
参数：`kinds`(逗号分隔, 默认全部) `min_degree`(默认1) `keyword` `focus`(节点 id) `hop`(1或2) `limit`(默认600)
```json
{
  "nodes":[{"id":"lit:LIT-000001","kind":"lit","label":"题名…","lit_id":"LIT-000001","weight":10}],
  "edges":[{"src":"lit:LIT-000001","dst":"img:IMG-…","rel":"contains","lit_id":"LIT-000001","weight":1}],
  "stats": {"nodes": 1200, "edges": 3400, "components": 12, "max_component": 900,
            "truncated": true, "returned_nodes": 600}
}
```
**口径**：`stats` 是**筛选后**重算的；`returned_*` 是实际返回的（受 limit 截断时 `truncated=true`）。界面必须同时显示这两组数。

### 2.7 `GET /api/graph/analysis`
```json
{
  "degree_top": [{"id":"...","label":"...","degree":42}],
  "betweenness_top": [{"id":"...","label":"...","betweenness":0.194}],
  "communities": [{"cid":0,"size":37,"members":8,"sample_labels":["...","..."]}],
  "note": "Louvain seed=42 固定；社区未自动命名，sample_labels 仅供参考"
}
```
**度中心性 ≠ 权责边界，介数才是**（报告口径）。

### 2.8 `GET /api/graph/evidence?src=&dst=&rel=`
```json
{"items":[{"lit_id":"LIT-000001","title":"...","path":"...","evidence":"证据文本","fig_no":"图1","pdf_page":"4","caption":"图注"}]}
```
证据来自：`lit→img` 边 → 该图的图注/页码/路径；`lit→tag` 边 → 登记表标签原文；`cocite` 边 → 双方共同标签清单。**每条证据都必须能点回原始文献**。

### 2.9 `GET /api/search?q=&...`
等价于 §2.2 的 `q` 命中路径，但**额外返回命中位置**：
```json
{"total": 42, "items":[...], "hits":[{"lit_id":"...","kind":"md|json|title","snippet":"...标记命中词的片段..."}]}
```

### 2.10 导出
| 路径 | 产出 |
|---|---|
| `GET /api/export/literatures.csv` | 当前筛选条件下的文献表（UTF-8 BOM，Excel 可直接开） |
| `GET /api/export/images.csv` | 图像表 |
| `GET /api/export/nbkg.csv` | **主库字段映射导出**（见 §4） |
| `GET /api/export/graph.html` | **离线自包含 HTML 图谱**（内联 vis-network，双击即开，断网可用，**零 CDN 外链**） |

### 2.11 `GET /api/health`
`{"ok": true, "db": "data/lzkg.db", "schema_version": "...", "counts": {...}}`

### 2.12 `GET /media/img/{filename}`（图版文件）

浏览器**读不到** `04_文献图像/` 下的文件（它在服务根目录之外），所以由后端代理：

- 路径：`/media/img/{filename}`，只允许单层文件名（不含 `/`、`..`）
- 实际位置：`<source_root>/04_文献图像/{filename}`；文件不存在 → 404
- 命中返回 `FileResponse`（带正确 content-type）；未命中返回占位 SVG（**不要 500**）
- 前端 `<img src="/media/img/{encodeURIComponent(filename)}">`

## 3. 前端（单文件 `web/static/index.html`）

- 顶部页签：**总览 / 浏览 / 检索 / 详情 / 图谱**（+ 详情从列表点入，不占独立页签）
- **零 CDN**：所有 JS/CSS 内联或本地相对路径；判据是**产物内无 `http(s)` 外链**
- 中文界面，字体栈含 `Microsoft YaHei`
- 关键词命中**标黄**
- 每个页面都要显示**数据口径**（如总条数、筛选后条数、复核覆盖率）
- 图谱页用 vis-network（后端 `/api/export/graph.html` 同款内联），支持：按类型多选 / 最小度数 / 关键词 / 聚焦+跳数
- **点边 → 右侧显示证据**（文献题名 + 证据文本 + 图注 + 页码 + 「打开文献」跳转）
- 图谱页必须显示：`返回节点/边数` 与 `筛选后总节点/边数` **两个口径**（截断时明确标注已截断）

## 4. 主库字段映射导出（`/api/export/nbkg.csv`）

并入 **宁波地域文明探源工程考古数据库**（`https://nbkg.nitlab.top/`）的字段对照：

| 本库列 | 主库字段（示意） | 说明 |
|---|---|---|
| `lit_id` | 文献标识符 | 建议 `NB-LIT-` 前缀 |
| `doc_type` | 文献类型 | 保留受控词表代码 |
| `title` / `authors` / `year` / `venue` / `publisher` | 题名/责任者/出版时间/载体题名/出版者 | 直接对应 |
| `abstract` / `keywords` | 摘要/关键词 | 直接对应 |
| `source_url` / `source_type` / `source_evidence` | 来源链接/来源类型/来源判据 | **本库最强项**，主库需要来源可回溯 |
| `period_tags` `region_tags` `topic_tags` `lineage_tags` | 四维标签 | 导出时**拆成多行或 `;` 分隔 + 保留代码** |
| `open_type` | 使用条件 | **决定能不能公开** |
| `pdf_path` / `md_path` | 存储地址 | 相对路径 |
| `md_chars`/`md_pages`/`md_img_refs` | 解析统计 | 供主库体检 |

导出文件必须带**口径页脚**（导出时间、筛选条件、总条数）。
