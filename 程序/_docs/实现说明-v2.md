**响应（实测）**

    "diffs": [

        "fields": [
          {"col": "题名",
           "old": "基于ArcGIS Geodatabase的浙江良渚古城遗址空间数据库的设计与实现",
           "new": "基于ArcGIS Geodatabase的浙江良渚古城遗址空间数据库的设计与实现【自测改动】",
           "required": true}

**怎么实现的**

1. 上传文件落到**临时目录**（`tempfile.TemporaryDirectory`），用
   `sheetio.read_rows_by_column()` 读 —— **复用已有的「按列名定位表头」逻辑**，
   没有另写一套。
2. 逐行与主库对比：主键 `lit_id` / `img_id`（`registry.pk_field()` 取，
   不是写死的）。`op` ∈ `new` / `changed` / `same`；
   `fields[]` 只报**真的变了**的列，带 `required` 标记。
3. **有变化的行写进 `staging`**（`status='pending'`，带 `batch` 批次号与
   `filename`），**主库一行不动**。
4. **缺必填列 → 400**，错误里说清缺哪几列（列名带 `*` 标记）。

> ★ 必填集合按**变体**裁剪：32 列模板没有「数据来源类型*」，它只对最终版必填。
> 判据是「表头里有没有完整版专属列」—— 用 `registry.required_columns(table, variant)`，
> 不是硬编码名单。

### 2.2 P2 · 账号

#### `POST /api/auth/login`

```json
{"ok":true,"data":{
  "token":"GnXc9_NLPyPk4vuFLtxYUTtipcu7ickn0ueQq_S3fL0",
  "user":{"username":"admin","role":"admin"},
  "must_change_password":true,
  "note":"当前仍在用初始密码，请尽快修改（POST /api/auth/password）。"}}
```

- 密码哈希：`hashlib.scrypt`，格式 `scrypt$n$r$p$salt$dk`
  （`scrypt$16384$8$1$<salt_hex>$<dk_hex>`），**标准库零依赖**。
- **首次登录必须提示改密码** → `must_change_password=true`。
- 账号不存在与密码错误**给同一条错误**（不泄露用户名是否存在）。

#### `POST /api/auth/logout` → `{"ok":true}`

#### `GET /api/auth/me`

```json
{"ok":true,"data":{"user":{"username":"admin","role":"admin","implicit_login":false}}}
```

未登录 → `401 {"ok":false,"error":"请先登录"}`。

#### `POST /api/auth/password`（body：`{"old":"…","new":"…"}`）

```json
{"ok":true,"data":{"username":"admin","changed_at":"2026-10-28 19:12:39",
  "note":"密码已更新；该用户的所有会话已失效，需重新登录。"}}
```

★ 改密码后**该用户所有会话失效**（别人还拿着旧 token）。

#### 权限：两道锁

- `auth.enabled=false`（**默认**）→ 全员免登录、视为 `admin`（本机演示方便）。
- `auth.enabled=true` → 走真实账号：
  - 未登录访问受保护端点 → **401**
  - 登录了但 `role != 'admin'` → **403**（自测实测：member 调 `/api/diagnose`
    与 `/api/staging/{id}/approve` 都是 403）

## 7. 前端对接提示（给写前端的人）

- 新端点一律 `{"ok":true,"data":{…}}`；失败 `{"ok":false,"error":"…"}` + 语义状态码。
- token 放请求头 **`X-Auth-Token`**。

  后端 `require_admin` 是第二道锁（手工构造请求只得到 403）。
- 导出 xlsx 的下载文件名由服务端定（`filename*`），前端直接 `a.download` 即可。
- `/api/stats/map.png` 直接当 `<img src>` 用；响应头 `X-Chart-Mode` 可让界面
  显示「坐标待补，当前显示分区统计」。
- `/api/ai/ask` 的 `degraded=true` 时，`answer` **已经是**检索结果摘要，
  界面应照原样显示，**不要**再包装成「AI 回答」。
