# 数据包放这里

这个文件夹是**空的，等你把数据包放进来**。

## 一句话做法

1. 拿到「良渚文化原始数据包_v3.8.zip」（约 1.9 GB）
2. 解压 → 得到一个叫 **良渚文化原始数据** 的文件夹
3. 把这个文件夹**整个拖进本目录**（即 数据包/良渚文化原始数据/）
4. 回到网站刷新页面 → **图版缩略图、原文 PDF/Markdown 立刻可用**

不用改任何配置文件，不用敲命令，**放进去就生效**（连重启都不用）。

## 为什么需要它

对接包里带的是**库**（题录、图版标注、全文索引），
不带**文件本体**（图版图片、原始 PDF、MinerU 解析出来的 Markdown）——
这些是机构订阅件，不进公开包。

所以「装好对接包但没放数据包」时，站点是这样表现的：

| 功能 | 表现 |
|---|---|
| 图版缩略图 | 全部显示「图版未找到」占位图 |
| 阅读原文（Markdown / PDF） | 提示「原文文件不在数据源目录里」 |
| 检索、图谱、统计 | **照常可用**（全文已入库，不需要文件本体） |

**这三种缺文件的表现长得一模一样**，所以工作台里有「数据包」卡片，
一眼就能看出是「没放数据包」还是「这篇本来就没有」。

## 放进去以后怎么看

- 工作台 → **⑪ 数据包（图片 / 原文）**：逐项显示「图版 3162/3162」「原文 Markdown 200/200」、
  「原文 PDF 200/200」「登记表 2/2」，以及解锁了哪些功能。
- 没放或没放齐时，那里会**明写**缺什么。

## 目录名不用统一

程序**按内容认**，不按名字认：只要里面有这 5 个子目录就行 ——
01_原始资料、02_解析结果、03_文献全文、04_文献图像、05_登记表。

所以「良渚文化原始数据」「04_专题研究」两种名字都能用，
不必重命名，也不必重打 1.9 GB 的包。

> 注：本文件夹**只放说明**，不随对接包带原始数据（订阅件不进公开包）。
> 打包脚本有一条红线：数据包/ 里除了本说明以外出现任何文件，都拒绝出包。
