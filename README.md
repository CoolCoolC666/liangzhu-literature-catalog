# 良渚文化文献目录站

> 浙江大学《数字文化技术》课程作业 · **独立项目** · **公开仓库（脱敏发布版）**
> 目标：把良渚组第一阶段攒的 200 篇文献 + 3 162 张图版 + 原始解析 JSON，
> 做成一个能在浏览器里**浏览、检索、看详情、回溯来源**的单页网站，
> 外加一个**可解释的关联图谱**与**分档标精度的地图标记**。

---

## 一、这个仓库里有什么、没有什么

| 有 | 没有（**故意不带**） |
|---|---|
| 全部程序代码（FastAPI + SQLite + 单页前端） | **数据库**（347 MB，含 CNKI 机构订阅全文与 203 份原始 JSON） |
| 验收脚本（283 项判据，可独立运行） | 图片与图版原文件 |
| 接口契约 / 实现说明 / 工程约定 | 运行日志、pid、浏览记录 |
| 离线底图（精简版，Natural Earth 公共域 + OSM） | **任何凭据**：AI key、WebDAV 密码、MinerU token、初始口令 |
| 坐标台账与受控词表 | 本机绝对路径、隧道 ID、Access 应用 ID、Access aud |

### ★ 为什么数据库不进仓库（这是硬红线，不是嫌大）

课程登记表里的「开放类型 / 使用条件」列写明：
**机构订阅取得的文献不得公开外传**。
本项目的库里有 **201 篇 Markdown 全文**与 **202 份原始 JSON**（CNKI 下载原件）——
把它们放进公开仓库，等于把机构订阅内容公开发布。

→ 所以**公开的只是「方法与工具」**。数据要自己按 README 重建。
→ 坐标台账（`程序/data/坐标证据台账.txt`）留在了仓库里：
它是**事实性坐标与出处**，不含全文，属于可公开的学术成果。

## 三、跑起来

```powershell
cd 程序
pip install -r requirements.txt
python -m lzkg doctor      # 自检：依赖、目录、库
python -m lzkg set-source "<你的 04_专题研究 目录>"
python -m lzkg migrate     # 建库：登记表 + MD + JSON → SQLite（幂等）
python -m lzkg serve       # 起服务 → http://127.0.0.1:8771/
```

Windows 上可以直接双击薄壳（**手动启停，不注册开机自启**）：

| 文件 | 作用 |
|---|---|
| `程序/启动.cmd` | 起服务 + 自动开浏览器 |
| `程序/停止.cmd` | 按 PID 停服务 |
| `程序/启动-公网.cmd` / `停止-公网.cmd` | 挂 Cloudflare Tunnel（手动启停） |

### 验收

```powershell
python 程序/tests/test_all.py --api --layout     # 169 项
python 程序/tests/test_graphview.py --api        # 48 项（图谱降密 + 地图标记）
```

判据一律写成「**必须等于某个实测真值**」，而不是「不为空」——
**断言「产物合法」≠ 断言「产物正确」**。

★ **本仓库不带数据库**，所以刚 clone 下来时数据层判据会自动跳过并提示你去建库
（`migrate` 之后全部可跑）。**不依赖数据的纯代码判据**（WebDAV 全链路、前端函数）
开箱即可通过。

## 四、这个站做了什么

| 页签 | 内容 |
|---|---|
| **总览** | 库规模、标签、来源构成、图谱概览 |
| **文献** | 浏览 + 检索（两级降级：短词走 LIKE，长词走 FTS5）、多轴筛选、收藏 |
| **详情** | 题录 / 摘要 / 四维标签 / **地图标记** / 去哪核实 / 图版 / 原始 JSON / 相似文献 |
| **图谱** | 点边出证据；**降密度后**的子图布局、标签分级与渐进披露 |
| **工作台** | 统计与地图、MinerU 解析与录入、导入导出与协作提案、账号、Web Dev 浏览数据同步、MCP |

两个值得一提的实现：

### ★ 图谱降密度：三处一起治

用户反馈「图谱过于密集」。先把「挤」**量化**（最近邻距离中位数），
再定治法 —— 「看着挤」写不进判据。

- **边按度数上限裁剪**（不是「每节点保 top-k 条」——那对 hub 无效）
- **按裁剪后的子图重算布局**（不是拿全图坐标裁一遍 ——那样 hub 全挤在簇心）
- **标签给「社区代表」而不是「度数最高」**，并按缩放**渐进披露**

实测：600 节点 / 7 179 边 → 505 节点 / 1 012 边，最大度数 263 → 12，
最近邻中位距离 8.8px → 14.3px。布局**跨进程可复现**（固定 seed + 按 key 排序建图）。

### ★ 坐标分四档标精度

文献坐标（米级，本篇/他篇提供）｜公开权威坐标 ｜ 分区代表点（±1.1 km）｜未定位。

- **不命中就是「未定位」，不推测填充** —— 小地图宁可留空并写明原因，也不画假位置
- **主题类分区不配点** —— 给它一个点就是在编造位置
- 坐标系只认 **WGS84**；高德/百度的加密坐标有几百米系统误差，不得冒充

## 五、数据与合规

- 站点**默认只监听 127.0.0.1**；挂公网时建议开 Cloudflare Access 邮箱验证。
- 各人的 **AI key / WebDAV 密码 / MinerU token 只存在自己浏览器**里，
  本站不保存；但它们会随请求经过本机后端再转发（浏览器直连被 CORS 挡）。
- 图版经本机后端代理读取，**不直链站方**。
- AI 标注只是**候选标注**，不是考古结论。
