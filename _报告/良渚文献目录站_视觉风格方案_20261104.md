# 良渚文献目录站 · 视觉风格方案：工程图纸

> 日期：2026-11-04　｜　状态：**样例版已落地（仅图版检索页），待确认后推广**
> 开关：站点顶栏右上角「风格：图纸 / 原版」，状态记在浏览器本地（localStorage `lzkg.theme`）

---

## 一、为什么换

现版本是**通用数据库后台**的样子：冷灰底（`#f5f7f9`）+ 白卡 + 1px 灰边 + 6px 圆角 + 一支青蓝主色（`#1b6c8c`），
全站一套 `Microsoft YaHei`，标题只是「更大更粗」。诊断出四个问题：

| 问题 | 具体表现 | 后果 |
|---|---|---|
| 配色零识别度 | 换成任何数据集都成立 | 站点与「良渚」没有任何关系 |
| 排版只有一套字 | 标题/正文/数字同族同重 | 没有信息层级；数字用比例字，表格里会左右抖 |
| 结构等权 | `.card`/`.stat`/`.toolbar` 全是同一种白底灰边卡 | 层级靠一根 `border-left` 撑着 |
| 术语是工程语 | 「MD 正文字符」「原始 JSON 份数」「指纹一致」 | 这是给开发看的词，不是给读者看的 |

另有两处版面问题：图版检索页的卡片被长图注撑开、网格底部参差；顶栏「立即同步」是全站唯一实心主按钮，
视觉权重最高的元素跟业务无关。

## 二、为什么选「工程图纸」

良渚这个题目的底色是**考古 GIS**：城址坐标、水利系统、图版分层、探方测绘。工程图纸正是这类工作的原生视觉语言 ——
网格、等宽标注、图框、标题栏、角标。它同时满足两个要求：**技术感**（这门课叫《数字文化技术》）和
**可读性**（工具页需要密度，不能为了气质牺牲信息量）。

刻意避开的三个「AI 设计默认款」：暖奶油底 + 衬线 + 陶土色、近黑底 + 酸绿/朱红单亮色、报纸栏式零圆角密排。

## 三、令牌系统

### 颜色

| 角色 | 值 | 用在哪 |
|---|---|---|
| 深石墨底 | `#101619` | 壁纸 1 页面底 + 顶栏 |
| 宫墙墨绿 | `#2A514D` / `#24463F` | 壁纸 2 顶栏 / 页面底 |
| 描金 | `#C1925B` / `#E0B978` / `#8A6524` | 壁纸 2 的强调色三档 |
| 图纸网格 | `rgba(56,178,169,.07)` / 34px | 背景细网格（工程图的坐标纸） |
| 素纸 | `#F1F3F3` | 卡片、工具条、口径条 |
| 描边 | `#C4C9C9` | 卡片描边、分隔线 |
| **陶土主色** | `#B5672F`（品牌色） | 图号牌、角标、边框、印戳 |
| 亮陶土 | `#E3965C` | 深底上的文字与图标 |
| 深陶土 | `#8A4B18` | 素纸上的强调文字（对比度达标） |
| 按钮陶土 | `#A65A26` | 实心按钮底（白字达 WCAG AA） |
| 浅陶土 | `#F7EDE4` | 素纸上的浅色底 |
| 砖红 | `#8A3A2A` | 错误提示（与陶土同族） |
| 中性灰 | `#5E686B` / `#8A9599` | 待复核徽标、深底弱文 |
| 墨 | `#111A1E` / `#5C6E76` / `#7E9299` | 正文 / 次要 / 弱 |

★ **一页只留一支强调色**：陶土是唯一的强调色，错误用同族砖红，**待复核徽标改成中性虚线框**（不用第二个色相）。
★ 中性色是**冷石墨**（不是暖奶油）—— 冷灰底 + 陶土强调，与暖米色 + 黄铜那一套拉开距离。

### 字体（零外链 → 只能用系统字体）

| 角色 | 栈 |
|---|---|
| 数据与标注 | `Consolas, "Cascadia Mono", ui-monospace, monospace`（编号、计数、图号牌、口径读数） |
| 正文 | `Microsoft YaHei, "PingFang SC", "Noto Sans SC", sans-serif`（保持原样） |
| 标题 | 仍用正文族，**靠字距与字号建立层级**（不引衬线体，避免落进默认款） |

★ 组员机器不一定装了思源宋体/霞鹜文楷，所以字体栈只写**Windows 必然有**的族。
数字统一 `font-variant-numeric: tabular-nums`，让统计数字在表格里对齐。

### 形状与密度

- 圆角一律收到 **2px**（图纸是直的，只有 4–6px 圆角才像 SaaS 卡片）；
- 描边 1px，用 `#B9C6C4` 而非更深的灰 —— 深底上卡片靠**明度对比**立起来，不靠阴影；
- 间距沿用现有 8/12/16/20 节奏，不重排版。

## 四、三个签名元素

1. **图号牌**：每张图版缩略图左下角一块深底等宽牌，写 `LIT-000001 / 图11` —— 工程图的标题栏。
2. **图框角标**：卡片左上角一个青色 L 形角标 + 缩略图上叠一层 16px 细网格 —— 让图像像工程图而不是普通照片。
3. **工程标题条**：每页顶部一行大标题（字距 8px）+ 一行等宽英文 + 右侧一排等宽读数（库内/覆盖/命中）。

## 五、已落地：图版检索页样例

| 维度 | 做法 |
|---|---|
| 主题实现 | 独立样式块 `<style id="bpTheme">`，全部挂在 `body.bp` 下 —— **不污染原版样式** |
| 开关 | 顶栏「风格」按钮，`bpApply/bpInit`，状态存 `localStorage` |
| 页头 | 新增 `.pagehead`：中文大标题 + `PLATE INDEX` 等宽英文 + 三个**现算**读数 |
| 卡片 | 直角、素纸、图号牌、角标、网格叠加；题名截断 3 行、摘要截断 2 行 → **消除高度参差** |
| 「打开该文献」 | 从描边按钮降为文字链 —— 一个点击只做一件事，别抢主按钮 |
| 复核徽标 | 圆角药丸 → 直角等宽「印戳」 |
| 图表与页脚 | 条形图、SVG 图、页脚统一到陶土 / 深底 |
| 判据 | `tests/test_imgsearch.py` **判据 18**（18 项），该文件 41 → **59 项**；全库 445 → **463 项** |

★ 判据口径：主题三色必须与本文件逐字一致；读数必须 `fmtNum` 现算、不写死；图号牌不得出现重复的「图 图」；
主题样式里不得出现 `url(http…)` 外链。

## 五之二、多壁纸：一套令牌 = 一张壁纸

主题样式全部收在 `--bp-*` 令牌里（当前 14 个），规则只有一条：**换壁纸不改任何一条选择器，只换令牌值。**

**结构：规则只有一份（`body.bp`），壁纸差异在 `body.bp.t-xxx` 的令牌里。**
换壁纸 = 换 class + 换令牌值，**不改任何选择器、不改任何 HTML 结构**。

| 壁纸 | class | 强调色 | 底色 | 卡片 | 布局 | 状态 |
|---|---|---|---|---|---|---|
| 工程图纸（陶土） | `body.bp.t-terra` | `#B5672F` 陶土 | `#101619` 深石墨 | `#F1F3F3` 素纸 | **图纸块**：白卡 + 图框角标 + 密排 | 默认 |
| 宫墙（墨绿 + 描金） | `body.bp.t-museum` | `#C1925B` 描金 | `#24463F` 墨绿 | `#F7F7F8` 纸白 | **图录画廊**：无卡、大图、展签式编号 | 已落地 |
| 原版 | 不加 class | `#1b6c8c` 青 | `#f5f7f9` 冷灰 | 白卡 | 后台 | 兜底 / 对照 |

★ 顶栏的切换器从「按钮」换成**下拉**（`#bp-theme`），三张壁纸随时切。
★ 每张壁纸的**令牌 16 个**（色板 + 圆角 + 遮罩），两套共 32 个 `--bp-*`。
★ 壁纸之间可以连**布局**一起换：宫墙壁纸把图版区从「白卡图纸块」改成「暗底画廊」，
图放大到 224px、题名放大、编号牌改成纸底金字的**展签**，信息密度整体降低。

**加一张壁纸要做的三件事**：

1. 新增一个 `body.bp.t-xxx{...}` 令牌块（复制现有的改值）；
2. （可选）新增一个 `body.bp.t-xxx` 布局块 —— 布局差异也只用 CSS 写；
3. 选择器里加一个 `<option value="xxx">`，并在 `bpInit` 的白名单里加上这个名字。

**参考：故宫博物院数字文物库**（<https://digicol.dpm.org.cn/>）

宫墙壁纸的色板与做法来自它：主色墨绿 `#2A514D`、强调色描金 `#C1925B`、纸白 `#F7F7F8`、
底色灰绿，标题用手写体、正文只用微软雅黑。它最值得偷的三点我们已经用上了：

- **编号是一等公民**（他们的 `故00083982 战国`，我们的 `LIT-000001 / 图11`）；
- **一页只留一支强调色**（金色用了 75 处，但从不用第二种色相做强调）；
- **低密度字段表**（一件文物只给 4 行字段，我们详情页 15+ 字段平铺是「后台味」的根源）。

**不照搬的**：他们是大图瀑布流的器物展示站，我们是检索工具 —— 密度、字段数、控件形态都要留。

## 七、检索页版式：照故宫数字文物库重排（v3.9-BP2）

**问题**：原来文献检索与图版检索都是「一长条工具栏 + 一栏结果」——
控件平铺在一条线上，类别筛选和结果混在一起，页面读起来像后台表单，
没有博物馆图录那种「先分类、再看结果」的秩序。

**改法**（参考 <https://digicol.dpm.org.cn/> 的检索页结构）：

| 位置 | 内容 |
|---|---|
| 顶部搜索行 | 关键词输入框 + 检索方式 + 应用/重置 + 导出当前结果 CSV |
| 左分类栏（sticky） | 类别筛选（类型/语种/年份/分期/空间/主题/谱系）、排序与展示、数据管理 |
| 右结果区 | 口径条 + 结果列表（图版页多一个数据源提示块） |

- 左栏是 sticky 侧栏，滚动时**不跟着跑**；窄屏（≤900px）自动折叠成上下两块。
- 图版页左栏多一组「结果视图」切换：**网格 / 列表**。
  - 网格＝原来的图版卡（缩略图 + 题名 + 摘要 + 徽标）；
  - 列表＝一行一条（左缩略图 / 中题名摘要徽标 / 右编号与「打开该文献」）。
  - 切换**只换呈现，不重新检索**（view 不发给后端，纯前端状态）。
- 文献页补了工程标题条（文献检索 / LITERATURE INDEX），两个读数（库内篇数、当前命中）**现算**。
- 旧工具条函数整体拆掉，不留两套并存。

**约束不变**：零外链、ES5、点图看大图不跳文献、复核状态只显示不过滤、
排序与分页口径与原实现完全一致（只是摆放位置变了）。

**左栏瘦身与对比度修正**（v3.9-BP3）

- 「排序 / 每页」从左栏提到**顶部搜索行**（排序是全局设置，不是分类）；
- 「数据管理」四件套（导出 xlsx / 下载空白模板 / 导入登记表 / 录入一条）从左栏移到
  **结果区底部的横向工具条** —— 原先塞在侧栏里，会被侧栏自身的滚动区吃掉，用户根本够不着；
- 左栏现在**只剩类别筛选**，一屏放得下，不用在侧栏里上下找；
- **对比度**：
  - 宫墙壁纸下深底上的标题（「工作台」等子界面标题）原用 --brand（深墨绿）落在墨绿底上，等于隐形 →
    改走描金 --bp-accent-bright；
  - 弱文色 --bp-ink3 由 #A6B7B3 提亮到 #B9CAC6；
  - 侧栏里的 ghost 按钮原是「白底橙字」，在纸面上扎眼且对比度不达标 → 改成透明底 + 强调深色字；
  - 工作台卡片的标题、状态块、端点行、权限行统一走壁纸令牌。

**判据**：新增「判据 19 · 检索页版式」12 项，锁住版式三件套、
旧工具条已拆、视图切换纯前端、列表视图仍走大图查看器、读数现算、零外链。

## 七、约束与边界

- **零外链**：不引任何 CDN 字体/图标/图片；网格、角标、图号牌全是 CSS。
- **ES5**：新代码全部 ES5（`var` / `function`），过 `node --check`。
- **对比度**：深底正文 `#EAF2F1`、弱文 `#7E9299`；白卡正文 `#111A1E`、次要 `#5C6E76`。
- **可访问性**：`:focus-visible` 给出 2px 青色焦点框，键盘能看见焦点。
- **可回退**：开关随时切回「原版」，原版样式一行未改。
