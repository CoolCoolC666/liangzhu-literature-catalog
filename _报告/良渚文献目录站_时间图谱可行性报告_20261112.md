## 〇、一句话结论

**技术上完全可行，而且不需要新增任何数据源**：你要的「横纵坐标 + 地图 + 点点看文物图片和文献」这条链，
现有库里**三段数据都是现成的**（文献 200 篇带出版年、3162 张图版带图注、12 个空间分区带代表点），
前端也**已有可复用的骨架**（统计页的四图层地图、点位详情抽屉、图版卡片）。

**唯一真正需要你拍板的，是 Y 轴**——而且不是技术问题，是口径问题：
「良渚文化的时间图谱」里的"时间"，可以指**研究史时间**（文献出版年，1984–2026，库里 200/200 篇全有），
也可以指**考古年代**（良渚早/中/晚期，库里只有 7 个粗分期标签、**没有任何绝对年代**）。
这两条时间线不是一回事，混在一张图上必然读错。

> ★ **红线**：库里没有绝对年代（3300–2300 BCE 这类）。要画考古年代轴，
> 就必须人工从原始文献抄录绝对年代 —— 那是**新增数据**（跟「18 个单遗址坐标人工抄录」同类的工作量），
> 不是本轮能顺手做掉的。本报告按**不编数据**的规矩，把这条列为"阶段 2 备选"，不写进阶段 1。

**浏览器实测**（中文 / English / 日本語三语都过）：

- 点文献点 → 右侧抽屉出该文献的**图版缩略图 + 图注/页码/图型/对象/复核状态**，并提示「其中 N 张尚未人工复核」；带「打开文献详情」「在文献页筛选」；

**这一轮修掉的三个真问题**（都是实测发现的，不是想当然）：

1. `isDim()` 里 `if (!s) return false;` 会让「按分区高亮」在**未选中任何点时整段被跳过** → 反向联动看起来毫无反应；
2. 分区名有两套写法（带编码 `R-0101 良渚古城` / 不带 `良渚古城`），比较前必须统一去编码，否则永远不相等；
3. X 轴斜排标签在窄版式互相压字、最后一列被裁 → 长名拆两行 ＋ 右侧留 66 px。

## 一、把你的原始描述拆成可判定的需求

> 「通过横纵坐标表示良渚文化的时间图谱与一个还没有确认的 Y 坐标，同时插入一个地图，
> 点击相关点可以展示其中的文物图片以及相关文献链接。」

拆成四条可验收的需求：

| # | 需求 | 可判定的说法 | 本轮可行性 |
|---|---|---|---|
| N1 | 横坐标 = 时间 | X 轴能把 200 篇文献按时间排开 | ✅ 现成（出版年 200/200 覆盖） |
| N2 | 纵坐标 = 待定 | Y 轴选一个**不需新增数据**的维度 | ⚠️ **需你拍板**（候选见第三节） |
| N3 | 插入一个地图 | 地图与时间轴**联动**，不是两张各看各的图 | ✅ 复用统计页已有地图 |
| N4 | 点点看文物图片 + 文献链接 | 点时间轴的点或地图的点 → 出图版 + 文献 | ✅ 图版 3162 张带图注、174/200 篇有图版 |

**隐含的第五件事**：地图上放什么点？库里"有坐标的东西"只有 10 个（4 个文献坐标点 ＋ 6 个有经纬度的分区代表点），
**18 个单遗址一个坐标都没有**。所以地图上的点**只能是分区/坐标点这一级**，不能是文献级——
除非先补坐标（那是另一件大工程）。

### 2.4 「江湖时序」能借什么、不能借什么

参考 [DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map)（宣纸设色古舆图，可拖动时间轴、点城读史）。

**可借（交互骨架，与我们的数据形态无关）**
1. **拖动时间轴刷选** → 地图跟着变；
2. **时间轴可缩放**：拖两端手柄放大某一段历史，双击恢复全览 → 正对我们 1984–2005 挤成缝的问题；
3. **时间轴内联"当年上下文"**（他们放"在位帝王+年号"，我们可放"该年文献数 / 图版数 / 主题构成"）；
4. **点事件 → 时间轴与地图同时跳转**（点史事回溯到那一年）；
5. **点城池 → 弹出"该地各时期卡片"** → 对应我们的"抽屉：该点位的图版 ＋ 文献"；
6. 快捷键：空格播放/暂停、Esc 关卡片。

**不能借（会破我们的红线）**
- ✗ **SVG 相机引擎**：换引擎等于重写，而且我们没有"疆域快照"这种数据；
- ✗ **历史疆界多阶段快照**：良渚没有这种数据，编出来就是编数据；
- ✗ **古海岸线/地形晕渲**：授权未核实（见 2026-11-08 口径），不进公开产物；
- ✗ **Google 书法体**：破零外链红线。

→ **结论：借交互，不借引擎、不借资产。** 地图继续用 Leaflet（本项目已 vendor），时间轴用原生 SVG/DOM 手写（ES5、零依赖）。

## 三、Y 轴候选方案（**这一节就是需要你拍板的地方**）

> 〔已拍板 2026-11-12〕**最终口径：X＝良渚文化分期带（8 档）、Y＝主题族带（S-08xx 码族 4 带）、出版年作格内纵向第三维。**
> 〔原述〕下文 §3.1 的推荐（X＝出版年）是拍板前的推荐，**原文保留**作留痕；订正见「〇之二」。

四个候选都按"不新增数据"筛过，逐个给实测支撑、优点、风险。

### 方案 A：研究主题族带（**推荐**）

- **Y = S-0801 / S-0802 / S-0803 / S-0804 四条带**（来自受控词表码族，实测 121/111/63/44 篇，均不空）
- **X = 出版年**（1984–2026，归一后 43 年）
- **点的粒度 = 文献**，一篇可落多条带（实测一篇平均带 1.7 族）
- 形态：**带状图**（4 行，每行一堆点/短条），不是散点——因为一篇多带

| 优点 | 风险／代价 |
|---|---|
| 数据现成、分类规则来自词表（不是现编的） | 一篇多带 → 同一点重复出现，界面要写清"点表示文献，条带表示主题归属" |
| 4 带都有量，能看出**研究热点的迁移**（1980–90 考古 → 2015+ 数字化/文创） | 带内点的横向密度还是右偏，需要区间缩放 |
| 天然回答"良渚研究在时间上怎么变的" | 一族内标签差异被抹平（要看细节得点进去） |

### 方案 B：良渚分期带

- **Y = 7 个分期**（晚期 117 / 当代 38 / 早中晚三期 14 / 中晚期 7 / 中期 5 / 早中期 3 / 崧泽-良渚过渡 1）

| 优点 | 风险／代价 |
|---|---|
| 概念上最"良渚"，直接回答"哪个时代被研究得多" | ★ **58.5% 的文献挤在"新石器时代晚期"一格**，图上是一条厚线，纵轴几乎退化 |
| 与考古叙事直接对应 | ★「当代」38 篇（含申遗后、数字化、文创）与考古分期**不是一回事**，混在同一根轴上会被读成"考古年代 = 现代" |
| — | 与方案 A 相比，Y 轴信息量明显更少 |

### 方案 C：空间（纬度）——「时间 × 空间」耦合图

- **X = 出版年，Y = 纬度**（把空间搬上纵轴，地图则作为同一批点的另一种投影）

| 优点 | 风险／代价 |
|---|---|
| ★ **Y 轴不用编**：是真实经纬度，与地图天然同源 | ★ **有坐标的点只有 10 个**（4 文献点 ＋ 6 分区点）→ 散点图极稀 |
| 是学界标准的 space-time 表达 | 每个点的文献是**关键词匹配**来的，口径要写明（不是"这篇文献研究的就是这个遗址"） |
| — | 与地图重复度高 |

### 方案 D：文献类型

- **Y = doc_type 9 类**

| 优点 | 风险／代价 |
|---|---|
| 数据最干净（受控词表单值字段） | ★ **学术论文 163/200 = 81.5%** → 纵轴 9 行里 1 行占八成，退化成一条时间直方图 |

### 3.1 推荐与组合建议

> 〔原述〕以下是拍板前的推荐（X＝出版年）；〔订正〕最终 X 轴改为**良渚文化分期带**，
> 主题族带仍作 Y 轴，出版年降为格内纵向。

**推荐：方案 A 为主视图**（X=出版年、Y=主题族带、点=文献），
**把方案 B（分期）与方案 C（空间）降级为编码维度而不是坐标轴**：

- **分期** → 点的**颜色/描边**（晚期/当代/跨期一眼可分）；
- **空间分区** → 点的**分组簇**或筛选条件；
- **地图** → 右栏，与时间轴共享筛选状态。

这样**一根纵轴就够**，且不出现"58.5% 挤一格"或"9 类里 8 类是学术论文"的退化。

**如果你要的是"考古时间轴"**（X 轴就是良渚绝对年代），那它**不在阶段 1**：
需要人工从原始文献抄录绝对年代（跟 18 个单遗址坐标同一类活），工作量按文献数算（200 篇里挑出有明确年代的），
建议单独立项。

## 八、风险与不做的事

1. **考古绝对年代 = 新增数据**，本轮不做（要人工抄录，另立项）。
2. **文献级空间点 = 需要 18 个单遗址坐标**，现在 0/18 → 地图上只有分区级点。
3. **图版 67% 待人工复核** → 抽屉必须显示复核状态，别让读者误以为是人工确认过的图。
4. **图版类型码位失真**：`img_type` 里"其他"占 62.8%、`obj_type`"其他"占 56.9% → 图版筛选要按**器物/照片**这类可用的粒度，不要承诺精细分类。
5. **出版年右偏**（2015 后占 64.5%）→ 必须做区间缩放，否则老文献看不见。
6. **分区标签多计**：一篇可带多个分区，合计大于 200，界面要标口径。
7. **不引入第三方时间轴库**（零外链/零依赖约束），手写 ES5 SVG。
8. **正文分区的图版数差 40 倍**（良渚古城 1383 vs 良渚遗址群 17）→ 抽屉默认"看前 N 张 + 可翻页"，别一次铺 1383 张。
